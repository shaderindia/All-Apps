Shader7 is a lightweight suite of eight browser tools and twenty-five technical guides with valid structured data. The primary barrier to organic indexing is an internal domain redirect mismatch where page canonical tags point to a bare domain that permanently redirects back to the live site. This audit outlines the single change to unlock indexing, seven supporting technical fixes, and four initial keywords to target.

Where the site stands

The website is responsive, loads rapidly via Cloudflare Pages, and offers practical browser utilities across engineering, photo editing, and finance. High-effort guides for CNC machining and passport preparation provide rich educational value, and the site carries verified ownership records for both Google and Bing.

However, organic search discovery is currently blocked by a circular signal. The live website serves traffic on www.shader7.com, but canonical tags and sitemaps point to the bare domain shader7.com, which returns a permanent redirect back to www. Aligning these signals to point directly to the live address is the essential first step.

If you only do one thing

Standardize all canonical tags, Open Graph tags, and sitemap entries to point directly to the live https://www.shader7.com address.

A canonical tag tells a search crawler (an automated search engine bot like Googlebot) which URL is the authoritative version of a page. Currently, every page on www.shader7.com specifies shader7.com as its canonical version. When Googlebot requests that URL, your server returns an HTTP 301 redirect (a permanent forward) right back to www.shader7.com. This circular loop causes search engines to pause or drop indexing across your pages.

  1. Update your repository to replace https://shader7.com/ with https://www.shader7.com/ in all rel="canonical" tags and Open Graph og:url tags.
  2. Update sitemap.xml so every page location starts with https://www.shader7.com/, and update robots.txt to reference Sitemap: https://www.shader7.com/sitemap.xml.
  3. Check the fix using a curl command or browser developer tools to verify that requesting a canonical URL yields an immediate HTTP 200 OK without any intermediate 301 redirect.

Small fixes, in order

Remove noindex pages from sitemap high

The file sitemap.xml submits six resume template URLs (such as cvbanao/template1/), but each template file contains <meta name="robots" content="noindex, nofollow">. This generates a direct "Submitted URL marked noindex" error in Google Search Console.

Fix: Delete the six cvbanao/template*/ entries from sitemap.xml so search crawlers only spend time reviewing pages you want displayed in search results.

Defer third-party advertising script medium

More than twenty pages load https://emotionallytonightintelligent.com/... directly inside the <head> element without defer or async attributes. This stops browser rendering while waiting for the remote ad network to respond.

Fix: Add defer to the script tag or relocate it to the bottom of the page before the closing </body> tag so content loads without delay.

Add nofollow to external file locker link medium

The passport photo page links directly to a MediaFire URL for an Android APK file: <a class="text-link" href="https://www.mediafire.com/.../PassportPhotoPro.apk/file" ...> without search bot guidance.

Fix: Host the installer file on your own domain or a GitHub release page. If keeping the external link, add rel="nofollow noopener noreferrer" so search engines do not associate your domain authority with an unvetted file host.

Add missing description and canonical on milling tool low

The page cnc-machinist/millingcalculation/index.html is missing both a meta description (the short summary text displayed below page titles in search results) and a canonical tag.

Fix: Add a meta description summarizing cutting speeds, feeds, and motor power calculations, and insert a canonical link pointing to https://www.shader7.com/cnc-machinist/millingcalculation/.

Add primary heading to triangle calculator low

The page cnc-machinist/Triangle/index.html contains zero <h1> tags (the main headline that tells search engines the primary subject of a document).

Fix: Add an <h1> element to the page header, such as <h1>Triangle Solver & Trigonometry Calculator</h1>, to provide clear document hierarchy.

Add descriptive alt text to tool banners low

On the home page directory, all tool preview images use empty alt attributes, such as <img alt="" src="/assets/banners/passport-640.webp">.

Fix: Replace empty quotes with concise descriptions, such as alt="Passport Photo Maker interface preview", to assist image indexing and screen reader accessibility.

Update robots.txt sitemap reference low

The directive in robots.txt points to Sitemap: https://shader7.com/sitemap.xml, which triggers an unnecessary 301 redirect before reaching the actual file.

Fix: Update the reference in robots.txt to read Sitemap: https://www.shader7.com/sitemap.xml.
