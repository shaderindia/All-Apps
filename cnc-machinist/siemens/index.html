Welcome to the Sinumerik G-Code Suite

Siemens Sinumerik controls (including the 840D, 828D, and 808D) utilize a sophisticated, high-level CNC programming language. Unlike ISO standard G-code (Fanuc/Haas), Siemens supports named variables, parameterizable canned cycles, local contour labels, and advanced tool management. This suite provides professional shop-floor tools to write correct Siemens turning code and generate standardized offset setup cards.

G-Code Turning Fundamentals

Turning on Siemens systems is programmed in the G18 Z-X plane. Key preparatory commands:

CommandDescription
G18Select ZX Plane (Standard for Lathes)
G95Feed per Revolution (e.g. F0.25 = 0.25 mm/rev)
G96Constant Surface Speed (CSS in m/min)
LIMS=...Spindle RPM Clamping Limit during G96
G97Constant Spindle Speed (Direct RPM)
DIAMONDiameter programming active for X axis
G41 / G42Tool nose radius compensation Left / Right
G40Cancel tool nose radius compensation

CYCLE95 Parameter Reference Breakdown

Syntax: CYCLE95(NPP, MID, FALZ, FALX, FAL, FF1, FF2, FF3, VARI, DT, DAM, _VRT)

Parameter Name Explanation & Values
NPP Contour Name Contour subprogram name or an inline label range. Generated programs use "CONTOUR_START:CONTOUR_END" so the MPF stays self-contained.
MID Infeed Depth Maximum depth of cut per pass along radius (\(a_p\)), programmed as positive number.
FALZ / FALX Finishing Allowance Finishing allowance on longitudinal axis Z (FALZ) and diameter axis X (FALX).
FF1 Roughing Feed Feedrate for roughing passes along parallel contour lines.
FF2 Plunge Feed Feedrate for downward plunge moves into undercut contours.
FF3 Finishing Feed Feedrate for the final contour-following finishing cut.
VARI Machining Type 1–4 rough: longitudinal external, face external, longitudinal internal, face internal.
5–8 finish: the same four orientations. 9–12 complete: the same four orientations. This generator uses 1/3, 5/7 and 9/11 for longitudinal OD/ID.
