Model, program and simulate a part in Shader7 3D CAD Studio

A walkthrough of Shader7 3D CAD Studio: building parts from boxes and cylinders, setting stock and work offsets, adding clamp zones, generating CNC toolpaths in five controller dialects, simulating them and exporting STL.

Full CAD/CAM suites are powerful, but for a fixture plate, a simple bracket or a quick check of a program they can be slow to start and expensive to license. 3D CAD Studio in the Shader7 CNC Machinist hub is a lightweight browser modeler built for machinists. You build prismatic parts from boxes and cylinders, set up stock and a work offset, choose an operation, generate G-code for your control and watch it run in a 3D simulation. You can also export the model as STL.

The workspace at a glance

  • Left panel (Setup): project and export, stock, solid primitives, part diagnostics, work coordinate system, keep-out zones, face selection, and CAM operation and tooling.
  • Centre viewport: the 3D model with ISO, TOP, FRONT and RIGHT views, Wire display and Fit to frame the part. A status line shows the active setup, for example 100 × 80 × 20 mm · G54 · Facing.
  • Right side: the simulation controls and the CNC Program output with Copy and Download .nc.

1. Project, units and files

  • NC Output Units: Millimetres or Inches. The model and STL always stay in millimetres; choosing inches converts every NC coordinate, distance and feed in the output.
  • Save JSON / Open JSON stores the whole project so you can continue later or share it.
  • Download .STL exports the model for 3D printing or another CAD/CAM system, using the current preview tessellation.
  • Reset, Undo and Redo.

2. Stock

Tick Use machining stock before generating toolpaths. Leave it off for a blank modeling workspace. Set L × W × H, and optionally a top chamfer on chosen sides (−X, +X, −Y, +Y) and a corner radius on chosen corners (front-left, front-right, back-left, back-right). Press Update Stock to apply.

3. Modeling with solid primitives

Add a Box or Cylinder, then set its Mode:

  • Add (Boss / Extrusion) to join it to the part.
  • Subtract (Pocket / Hole) to cut it away.

Each object has a base position (X, Y, Z), length, width and height, plus an optional chamfer on the top edge and corner radius, chosen per side and per corner. Move the selected object by dragging the X, Y or Z gizmo, or nudge it with the arrow keys (X and Y) and Page Up / Page Down (Z) using the Move increment you set. Delete removes the selected object and Clear All empties the scene.

This add/subtract approach (constructive solid geometry) covers most fixture plates, brackets, blocks with pockets, and bosses with holes.

4. Part diagnostics and weight

The Part Diagnostics & Mass panel shows the model's volume and an estimated weight for the material you choose: aluminium 6061, carbon steel 1018, brass/bronze, acetal/Delrin, or ABS/PLA plastic. It is a quick way to check shipping weight or whether a part is too heavy to lift into the vise by hand.

5. Work coordinate system

  • WCS Code: G54 to G59.
  • Datum Preset: Center Top, Front-Left Top, Front-Left Bottom, or Custom Coordinates.
  • Set XYZ to type a datum, or Pick On Model to click a point on the part.

The datum is where all program coordinates are measured from, so match it to how you will touch off the part on the machine.

6. Keep-out and clamp zones

Add Rectangle or Circle zones with a centre, width and height to mark clamps, vise jaws or bolts. Toolpaths avoid these areas, which is useful on fixture plates and when the part is held with toe clamps.

7. Choosing what to machine

Use Select Face to pick the face to machine; if no face is selected, the highest exposed face is used. Select Sides picks side faces for contour work.

8. CAM operation and tooling

Controller Dialect: Fanuc / Haas ISO, Siemens Sinumerik (840D/828D), LinuxCNC style, Expanded G-code (no canned cycles), or Parametric Macro.

Operations:

Operation Typical use
Surface Milling (Facing) Clean up the top face
Pocket Clearing Rough out pockets
Contour (Side Faces) Profile the outside or chosen sides
Drilling (Peck / Direct) Holes, with a peck depth Q (0 = G81)
PCD / Bolt Circle Holes on a pitch circle with centre, PCD, count and start angle
Rigid Tapping Threaded holes using the pitch
Center / Spot Drill Spotting before drilling
Precision Boring Finish bores
ID Circular Interpolation Mill a bore with a circle path
OD Circle Mill Mill a boss
Chamfer Contouring Break edges

Common tooling fields include Program #, Tool #, H Offset #, Tool Ø, Feed Rate, Plunge Feed, Spindle RPM, Safe Z, Retract Plane (R), Stock to Leave and Coolant (M08). Facing and pockets add Stepover %, Stepdown, Total Depth, raster direction (X or Y) and pattern (Zigzag or Climb (One-Way)).

Press Generate G-Code to create the program.

9. Simulate and verify

Use Run, Pause and Stop with a Sim Speed of 1×, 5×, 20× or 100× to watch the tool move through the stock. Check that the tool never enters a keep-out zone, that the depth is right and that rapid moves stay above the part.

The app reminds you that controller options, post conventions, work offsets and machine kinematics vary. Simulate on the target control as well, and use single block, dry run and reduced rapid override for the first run.

Where it fits

3D CAD Studio is ideal for prismatic parts, fixture plates, soft jaws, quick quotes and training. For complex freeform surfaces, 5-axis work or drawings with full tolerancing, use a full CAD/CAM system. Many shops use both: a quick model and program in the browser for simple jobs, the full system for the rest.

Example: a fixture plate in ten minutes

  1. Tick Use machining stock and set 200 × 150 × 20 mm, with a 2 mm corner radius on all four corners. Press Update Stock.
  2. Add a Box in Subtract mode, 120 × 60 × 8 mm, centred on the plate, to make a locating pocket. Give it a 6 mm corner radius so a standard end mill can cut it.
  3. Add four Cylinders in Subtract mode, 9 mm diameter and through the plate, near the corners for M8 mounting bolts.
  4. In Part Diagnostics, choose aluminium 6061 to see the plate's estimated weight.
  5. Set the WCS to G54 with the Front-Left Top datum, which matches how you will touch off the plate.
  6. Add two Rectangle keep-out zones where the toe clamps will sit.
  7. Choose Pocket Clearing, a 10 mm tool, 40% stepover and 2 mm stepdown, and press Generate G-Code.
  8. Run the simulation at 20× and check the tool stays out of the clamp zones.
  9. Generate a Drilling operation for the four holes, then Download .nc for each operation and Save JSON for the project.

Tips for clean models and programs

  • Match corner radii to your tools. An internal corner radius smaller than your cutter radius cannot be machined.
  • Name your files clearly. Save the JSON project with the part number and revision so the model and programs stay together.
  • Use inches only for output. Keep modeling in millimetres and switch NC Output Units to Inches if your machine runs in inches.
  • Check stock-to-leave. Leave 0.2–0.5 mm for roughing operations and finish with a second pass if the surface matters.

Frequently asked questions

Do I need to install anything?

No. 3D CAD Studio runs in a modern browser on desktop or tablet. A computer with a mouse is the most comfortable way to model.

Can I export my model?

Yes. Download .STL exports the model in millimetres. Save JSON stores the full project, including stock and setup, so you can reopen it later.

Which controls can it write code for?

Fanuc / Haas ISO, Siemens Sinumerik 840D/828D, LinuxCNC style, Expanded G-code without canned cycles, and a Parametric Macro dialect.

Can it program in inches?

Yes. Set NC Output Units to Inches. The model stays in millimetres, but the program's coordinates, distances and feeds are converted.

Does my model leave my computer?

Modeling, toolpath generation and simulation run in your browser. Use Save JSON to keep a copy of your project.
